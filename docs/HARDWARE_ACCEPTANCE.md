# 首次硬件验收：尚未执行

记录板型、固件 SHA、马达和驱动型号、电源电压/电流上限。拍接线照片。断电检查线序后上电，先测试默认低时长模式。

1. 上电/重置/串口连接时，马达均保持关闭，信号栅极有下拉。
2. `play hello` 实际感到两次短脉冲；示波器或逻辑分析仪确认 GPIO 90 ms 高占空比、100 ms 零输出、90 ms 高占空比，记录时间误差。
3. `stop` 在第一段时令输出归零；测实际停止延迟。ERM 的惯性可能继续转动，PWM 停止不等于机械立刻停止。
4. 按住外接按钮 10 s 只触发一次；放开、等待冷却、再按能重新触发。
5. 若使用 PN532，标签保持 10 s 只触发一次。移开至日志/波形显示离场，超过 500 ms 且冷却结束，再次靠近只触发一次。更换另一 UID 也需要离场再靠近。
6. 未知标签按配置 fallback 执行；把 fallback 设为 `null` 后应静默忽略。`learn` 只在本地串口输出一次 UID。
7. 检查马达启动/堵转是否造成主控掉电重启；测持续使用温升与电源峰值电流。不要为了测试持续堵转电机。
8. 连续做 30 次事件，记录漏触发、误触发、上电重触发与主观触感差异。量产前另做电气、EMC、电池及儿童/皮肤接触等适用验证。

通过桌面模拟不代表以上步骤通过。本仓库的测试还没有覆盖 PN532 射频干扰/读取故障与机械系统。
